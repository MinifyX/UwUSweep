# Changelog

## 0.1.0-beta.1

Erste Beta.

- App-Liste für Windows (Registry inkl. MSI, Store, winget), macOS (`.app`) und
  Linux (dpkg, pacman, rpm, Flatpak, Snap).
- Deinstallieren über den eigenen Deinstaller bzw. Paketmanager, unter Windows
  optional mit Wiederherstellungspunkt.
- Reste-Suche in den Stufen Sicher und Gründlich, Dateien und Registry.
- Quarantäne statt Löschen: Rückgängig per Klick, endgültig nach 30 Tagen.
- Installationen mitschreiben (Schnappschuss vorher/nachher).
- Autostart-Einträge ein- und ausschalten.
- Admin-Rechte nur bei Bedarf über einen geprüften Helfer.
- Setup für Windows (x64, ARM), macOS (universal), Linux (.deb, .rpm, portabel)
  und ein PKGBUILD für Arch.
